================================================================================
  CiRA FES - LLM Model Download Instructions
================================================================================

The LLM (Large Language Model) is OPTIONAL and must be downloaded separately.

MODEL LOCATION:
  C:\Users\<YourUsername>\AppData\Local\CiRA FES\models\

QUICK ACCESS:
  Press Win+R, type: %LOCALAPPDATA%\CiRA FES\models
  Press Enter

DOWNLOAD MODEL:
  1. Visit: https://huggingface.co/bartowski/Llama-3.2-3B-Instruct-GGUF
  2. Download: Llama-3.2-3B-Instruct-Q4_K_M.gguf (~2 GB)
  3. Place in the models folder above

FULL INSTRUCTIONS:
  See: docs\LLM_Model_Installation.md

NOTE:
  CiRA Studio works without the LLM model.
  The LLM provides AI-assisted feature selection and code generation.

================================================================================
